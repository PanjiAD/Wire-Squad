4. State overlays (composable)

Overlays are separate SVG groups drawn before or after the tile body, so states combine: selected target, hover marked. Target pulses (stops under reduced motion). Disabled is 35% desaturate. Info-marked adds a notch at the base where an info token attaches. Revealed has a green tick corner.

6. Sizing guide

Numerals use the heaviest display face; at 36 px wide the 28-34 unit numerals stay about 12-15 px tall. Under 28 px wide the UI switches to a zoom/focus view for the active stand.
