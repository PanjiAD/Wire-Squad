P8: Character cards
Five original animal trainees, template, captain variant, used state and a compact chip. No resemblance to any existing game mascot.

1. Template and five original characters

Top two thirds: character illustration waist-up in a red bomb-disposal jacket with a small badge, name ribbon. Bottom third: orange ribbon "Personal Equipment:" + item name + item icon. The item is data (personal_item), so other boxes can swap it. Each character has a distinct silhouette and a 4-color palette on top of the shared red jacket.

Solid red with a large empty-battery icon and "0%". Unmistakable from across the table: the card is red instead of white, and it carries a text label as well.
