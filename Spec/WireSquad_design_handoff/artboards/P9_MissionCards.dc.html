P9: Mission card template
Data-driven mission card: one template filled from JSON. Missions 1 to 8 only; TBD stays visible where the source data is not confirmed.

1. Template, front and back

75 x 110 proportion (300 x 440). Front: slanted title tab, big #N, one italic tagline, black SETUP panel with icon rows, bottom 2-player box. Back: black MISSION RULES panel (max 5 lines), red FAILURE block, green SUCCESS block, optional audio icon.

4. JSON to slots mapping and the CSS-only fill

The renderer sets one data attribute and a few custom properties per card. Nothing here needs JS to display text once the renderer wrote the markup.

SVG / HTML slotFills from JSON
#titletitle
#numberid (via data-n)
#taglinetagline
#setup-rowssetup.blue, .yellow, .red, .equipment (one row each, hidden if absent)
#twoplayer-boxtwoPlayer (dimmed if null)
#rulesrules[] (max 5 lines)
#failurefailure
#successsuccess
#audio-iconaudio (true shows speaker)
{ "id": 5, "title": "Second Day in the Field",
  "setup": { "blue": "all",
             "yellow": { "count": 2, "drawnFrom": 3, "markersFaceQuestion": true },
             "red": { "count": 1 }, "equipment": "players" },
  "twoPlayer": { "red": { "count": 2 }, "yellow": { "count": 2, "drawnFrom": 3 } },
  "rules": ["Draw 3 yellow wires..."], "success": "All wires cut.",
  "failure": "Dial reaches the skull or a red wire is cut.", "audio": false }
<article class="mc" data-n="5">                      /* number: no JS */
.mc .num:before { content: '#' attr(data-n); }
<span class="cnt" style="--v:'x2 out of 3'"></span>   /* counts: custom property */
.mc .rw .cnt:after { content: var(--v); }
.mc .two.dim { opacity:.45 }                          /* state from a class set by the renderer */
