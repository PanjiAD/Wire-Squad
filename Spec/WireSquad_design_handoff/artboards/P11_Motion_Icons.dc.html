3. Reduced-motion version

@media (prefers-reduced-motion: reduce) { .bb-a, .bb-a * { animation: bb-xfade 120ms both !important; animation-iteration-count: 1 !important; } }
Every motion becomes a 120ms cross-fade to its end state. The settings toggle "Reduced motion" adds the same class to the root so users can force it without an OS setting.
